# 프로밀리아 가이드 트래커

게임 **메모리를 읽지 않고**, 게임 화면 왼쪽 위의 **미니맵을 캡처**해서 [프로밀리아 가이드 지도](https://azur-promilia.pages.dev/map)에 내 위치를 보여 주고, 게임의 관측 기록 화면을 읽어 기록을 모아 주는 프로그램입니다. 예전의 메모리 방식 트래커(`promilia-tracker`)를 대신합니다.

- 게임 프로세스에 접근하지 않습니다(메모리 읽기 · 주입 없음). **관리자 권한이 필요 없습니다.**
- 캡처한 화면은 PC 밖으로 보내지 않습니다. 위치만 내 PC 안의 웹소켓(`ws://127.0.0.1:46822`)으로 사이트 지도에 전달합니다.
- 사이트는 기존 트래커와 같은 방식으로 받으므로, 지도에서 **내 위치 → 연동하기**를 그대로 쓰면 됩니다.

## 알아 둘 점

- **게임 화면이 보여야 합니다.** 가려지거나 최소화하면 읽지 못하고, 메뉴 · 지도 · 연출 화면에서는 위치를 잠시 놓칩니다.
- 위치는 약 1m 정확도, 초당 10번 안팎입니다. 높이는 지형 높이라서 건물 위 · 공중은 반영되지 않습니다.
- 관리자 권한이 필요 없습니다.
- 예전의 메모리 방식 트래커(`promilia-tracker`)와 같은 포트를 쓰므로 같이 켤 수 없습니다. 예전 트래커는 더 이상 쓰지 않습니다.

## 사용 방법

1. 게임을 켭니다. (창 모드 · 전체 화면 모두 되지만 게임 화면이 보여야 합니다)
2. `PromiliaGuideTracker.exe` 를 실행합니다. 처음 한 번 지도 그림을 사이트에서 받아 exe 옆 `maps/` 폴더에 둡니다.
3. **게임 창 찾음** · **미니맵으로 위치 찾음**이 뜨면 사이트 지도에서 **내 위치**를 누릅니다.

## 관측 기록 모으기 (화면 글자 인식)

게임에는 관측 기록을 내보내는 기능이 없고, 기록은 게임 화면에만 표시됩니다. 트래커는 그 화면의 글자를 Windows 내장 글자 인식(OCR · 한국어)으로 읽어 모읍니다.

1. 트래커를 켠 채로 게임에서 **관측 → 확률 설명 → 기록** 화면을 엽니다. 게임 화면이 다른 창에 가려지면 안 됩니다.
2. 왼쪽에서 관측 종류(운명 · 인연 · 일반 · 상시)를 하나 고릅니다.
3. 아래 화살표(→)로 **한 쪽에 1~2초씩 머물면서** 마지막 쪽까지 넘깁니다. 트래커 창의 관측 기록 칸에 "이번에 n쪽 읽음"이 올라가는지 보면서 넘기면 됩니다.
4. 다른 관측 종류도 같은 방법으로 넘깁니다.
5. 사이트 **나의 관측 결산**에서 **트래커에서 불러오기**를 누릅니다.

알아 둘 점

- **처음 한 번만 끝까지** 넘기면 됩니다. 다음부터는 지난번 이후 새로 관측한 만큼(앞쪽 몇 쪽)만 넘기면 이어서 쌓입니다. 이미 읽은 쪽을 다시 지나가도 중복으로 늘지 않습니다.
- 한 관측 종류를 넘길 때는 **차례대로**(다음 쪽 또는 이전 쪽으로) 넘겨 주세요. 페이지 번호가 꾸민 글꼴이라 읽히지 않아서, 쪽 순서를 넘긴 순서와 시각으로 맞춥니다.
- 넘기는 동안 화면을 계속 캡처해 두고 뒤따라 읽으므로 빠르게 넘겨도 됩니다. 다 넘긴 뒤 트래커 창의 '읽을 화면 n장 남음'이 사라질 때까지 기록 화면을 닫지 말고 잠깐 기다려 주세요.
- 화면의 시각은 분 단위입니다. 같은 분의 기록은 10줄씩을 10회 관측 한 번으로 보고 순서를 맞춥니다(게임은 10회 관측 안에서는 뽑힌 순서대로 보여 줍니다). 같은 분에 1회 관측과 10회 관측을 섞어 했다면 그 분 안의 순서는 틀릴 수 있습니다.
- 이름 · 카드풀 이름은 사이트 관측 자료의 목록과 맞춰서 번호로 바꿉니다. 목록과 맞지 않는 글자가 있는 쪽은 저장하지 않고 다시 읽습니다.
- 계정 UID 는 게임 화면 왼쪽 아래의 `UID:…` 글자를 읽습니다. 다른 계정으로 바뀌면 기록을 섞지 않고 새로 시작합니다(예전 파일은 이름을 바꿔 남김).
- 모은 기록은 exe 옆 `promilia-tracker2-gacha.json` 에만 저장합니다.
- 예전 트래커(메모리 방식)로 모아 둔 기록이 사이트에 있으면, 이 트래커의 기록을 불러올 때 그 계정의 예전 기록은 새 기록으로 바뀝니다(두 방식을 섞으면 같은 관측이 두 번 세어지기 때문).
- Windows 에 한국어 글자 인식이 없으면(한국어 언어 팩 미설치) 쓸 수 없습니다.
- 4K 전체 화면에서만 시험했습니다. 화면 비율이 16:9 가 아니거나 창 크기가 작으면 표 자리가 어긋날 수 있습니다.

## 동작 원리 (`locator.py`)

1. 게임 창 위치를 찾아(창 제목 `AzurPromilia`) 미니맵 자리만 캡처합니다. 미니맵 자리와 크기는 화면 세로 길이에 비례한다고 봅니다(세로 2160 기준 가운데 (285, 245) · 반지름 150px).
2. 캡처한 미니맵을 지도 그림(`base.webp`)과 비교합니다. 마스크를 씌운 정규화 상관을 numpy FFT 로 계산합니다. 미니맵이 반투명이고 가운데에 캐릭터 표시가 있어서 고리 모양 부분만 씁니다.
3. 처음이나 위치를 놓쳤을 때는 모든 지도 전체에서 찾고(약 1초), 붙은 뒤에는 직전 위치 둘레만 찾습니다(약 0.05초).
4. 지도 그림 위치를 게임 좌표로 바꿉니다(사이트 지도와 같은 식의 역변환). 높이는 3D 지형 높이 그림에서 읽습니다.

미니맵 축척은 새싹 골짜기에서 잰 값(세로 2160 화면에서 1m = 3.45px)입니다. 다르면 `promilia-tracker2.json` 에 `"px_per_m"` 으로 바꿀 수 있습니다.

## 아직 확인하지 못한 것

- 4K(3840×2160) 전체 화면, 새싹 골짜기에서만 시험했습니다. 다른 해상도 · 화면 비율 · 창 모드 · 다른 지역은 시험이 필요합니다.
- 미니맵이 회전하거나 확대 · 축소되는 설정이 게임에 있다면 지금은 대응하지 못합니다(북쪽 고정 · 기본 축척 기준).
- 실내처럼 미니맵이 다른 그림을 쓰는 곳에서는 찾지 못할 수 있습니다.

## 소스에서 실행 · 빌드

```powershell
pip install -r requirements.txt
python tracker2.py            # 화면 없이 상태만 보려면: python tracker2.py --nogui
.\build.bat                   # dist\PromiliaGuideTracker.exe (pip install pyinstaller 필요)
```
